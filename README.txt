DOVE CHAMBERS DEMO WEBSITE

QUICK PREVIEW
1. Open index.html in a modern browser.

FREE DEPLOYMENT (NETLIFY)
1. Go to https://app.netlify.com/drop
2. Drag the entire 'dove_site' folder onto the page.
3. Netlify will generate a public demo URL.

FILES
- index.html     Main website
- styles.css     Website styling and responsive layout
- script.js      Mobile navigation and lawyer profile pop-ups
- assets/        Images extracted from the supplied Dove Chambers profile

NOTES
- This is a presentation/demo site.
- Team biographies, client names, contact details and performance timeframes were adapted from the supplied firm profile and should be confirmed before a public launch.
- The site uses Google Fonts when an internet connection is available and falls back to system fonts otherwise.
